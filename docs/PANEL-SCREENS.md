# Чеклист экранов панели

Визуал: фон `#121212`, панели `#1a1a1a`, акцент `#5a9e4b`. Сайдбар слева, одна задача = одна страница.

## Обзор `/servers/:id`

- статус, имя, поддомен
- Старт / Стоп / Рестарт в липкой шапке
- адрес и IP с копированием
- последние 8 строк лога
- если спит — «нажми Старт»

## Моды `/servers/:id/addons` и `/addons/add`

- список установленных строками (вкл/выкл/удалить)
- «Найти» → каталог
- поиск с паузой 300 мс, без фриза ввода
- карточки, шторка, «Установить»
- прогресс скачивания в процентах/мегабайтах, не бесконечная крутилка

## Файлы `/servers/:id/files`

- дерево world / mods / plugins / config / logs
- список папки, крошки
- `.properties` / `.yml` / `.log` открываются в редакторе
- drag-and-drop загрузка с полосой прогресса
- jar в mods/plugins помечены «Моды»

## Настройки `/servers/:id/options`

Группы Игра / Мир / Производительность / Сеть / Иконка.
Не сырой ini. Ссылка «открыть server.properties в Файлах».
Сохранить → тост + бейдж «нужен рестарт».

Админка `/admin` в пользовательском сайдбаре не показывается (только telegram_id 1920838704).
